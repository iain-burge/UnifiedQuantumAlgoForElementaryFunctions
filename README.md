# UnifiedQuantumAlgoForElementaryFunctions
A Unified and Universal Algorithm to Efficiently Compute All Elementary Functions with Minimal Overhead.


Requirements:
Python 3.14.7
matplotlib        3.11.2
numpy             2.5.3


Note: Converting from the classical reversible algorithm to a quantum circuit is not finished, but will proceed identically to the methods used in the following REPO: https://github.com/iain-burge/QuantumCORDIC
